# Restaurante Japonês

## Sobre o projeto

O objetivo é criar um sistema para auxiliar no gerenciamento de um restaurante japonês, organizando informações de clientes, cardápio, funcionários, pedidos, itens, categorias e mesas.


## Funcionalidades

- Cadastro e gerenciamento de clientes;
- Cadastro e consulta de itens do cardápio;
- Cadastro e organização de categorias;
- Cadastro e gerenciamento de funcionários;
- Controle de pedidos;
- Controle de itens dos pedidos;
- Controle de mesas e seus status;
- Inserção, alteração, exclusão e consulta de dados;
